# Echoes of Lazarus – Roguelike Combat Game

**Echoes of Lazarus** is a roguelike combat game built using **Java Swing** 

## Features
- **Real-Time Combat** – Entities are fully animated and move in real time.
- **Frame-Based Combat System** – Startup, active, and recovery frames.
- **Loot & Progression** – Weighted rarity pool (Common → Mythic) with various items and weapons.
- **Enemy Spawning** – Enemies spawn in waves, different enemies will spawn based on player stats.
- **Boss Fight** – Multi-phase AI with varied attack patterns.

## Tech
- **Language:** Java
- **Graphics and UI:** Java Swing
- **Architecture:** Entity-component-system
